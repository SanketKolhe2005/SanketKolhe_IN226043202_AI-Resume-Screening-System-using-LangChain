# AI Resume Screening System

## Overview
This project is an AI-powered Resume Screening System built using LangChain.

## Features
- Skill Extraction
- Resume vs Job Description Matching
- Candidate Scoring (0–100)
- Explanation Generation

## Tech Stack
- Python
- LangChain
- LangSmith (Tracing)

## Pipeline
Resume → Extract → Match → Score → Explain

## Results
- Strong Candidate: 100
- Average Candidate: 44
- Weak Candidate: 0

## How to Run
python main.py
